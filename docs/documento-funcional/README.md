# Documento funcional AEGIS Urban

Documento funcional del proyecto organizado en las cuatro etapas del ciclo de vida. Cada etapa se puede leer por separado. Los diagramas y recursos visuales se guardan en [img/](img/).

> [!IMPORTANT]
> **Alcance:** AEGIS Urban es un prototipo de monitoreo, alertas y ejercicios urbanos. No reemplaza a los organismos oficiales ni debe presentar lecturas de sensores o simulaciones como instrucciones oficiales de emergencia. La integración con fuentes públicas autorizadas es trabajo futuro.
